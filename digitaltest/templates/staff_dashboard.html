Scoring formulas
Final score formulas
Final score = round(65 × accuracy + 15 × speed + 10 × precision + 5 × typing speed + 5 × typing accuracy)
accuracy = correct tasks / total tasks
speed = max(0, 1 - min(test time, 120) / 120)
precision = max(0, 1 - min(avg misclick distance, 500) / 500)
typing speed = max(0, 1 - min(typing duration, 30) / 30)
typing accuracy = typing accuracy / 100
Digital literacy score formulas
Digital literacy score = clamp(round(motor score × tech breadth × L factor × resource quality - penalty), 0, 100)
tech breadth = 0.7 + selected device weights from question 1
L factor = value from question 2
resource quality = highest selected value from question 3
penalty = value from question 4
